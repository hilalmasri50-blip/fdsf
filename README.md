# Nova Studio Website

A simple static website in plain HTML/CSS/JS.

## Easiest way to run

From this folder, run:

```bash
./run.sh
```

Then open:

- <http://localhost:4173>

## If `run.sh` does not work

Run Python directly:

```bash
python3 -m http.server --bind 0.0.0.0 4173
```

Then open:

- <http://localhost:4173>

## Stop the server

Press `Ctrl + C` in the terminal where it is running.
